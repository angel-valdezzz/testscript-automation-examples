# Experimental scope

The example runs the pinned 0.2 implementation while the MVP remains open.
Included: HTTP authentication, create/read/partial update, duplicate email,
lifecycle conflicts, validation, browser registration/login and negative forms.
Not claimed: savings/transfer parity, automatic expect retries, parallel execution,
automatic failure screenshots, or integration with the reporter libraries.
Browser screenshots are explicit. HTML/JSON/JUnit use TestScript's native reporter.
The service is the actual Demo Users API; no simplified fake is substituted.
